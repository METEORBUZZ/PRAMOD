# Pramod Ganvit — DevOps Portfolio

A professional DevOps/cloud portfolio built with React.js, Tailwind CSS, Node.js and Express.

## Features

- Responsive MNC-style dark DevOps UI
- Hero / About / Skills / Projects / Architecture / Contact
- AWS, Kubernetes, Docker, Linux, CI/CD and DevSecOps skill showcase
- Node.js Express contact API
- Contact submissions stored locally in `server/data/messages.json`
- Vite production build
- Ready for Docker/AWS/Kubernetes deployment

## Run locally

```bash
npm install
npm run dev
```

Frontend: http://localhost:5173  
API: http://localhost:5000/api/health

## Production

```bash
npm install
npm run build
npm start
```

Then open http://localhost:5000

## Customize

Edit `src/App.jsx` for portfolio text, skills, projects and social links.
